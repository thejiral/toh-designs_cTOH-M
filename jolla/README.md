The original TOH model for The Orange, Kaamos Black and Snow White TOHs is [toh-3d-model.step](toh-3d-model.step).
It can be 3D printed but it is not optimal as it has been designed for injection moulding and has too much detail.

Additionally memory chip content for those TOHs can be found in [toh-content repository](https://github.com/sailfishos/toh-content).
